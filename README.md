# sipl-tp-project
Проєктна робота "SIPL Toolkit" з дисципліни "Теорія програмування"

## Обраний набір завдань
|ID|Бали|Завдання |
|-|-|-|
|CORE-01|0.5|Формальна специфікація SIPL: машинозчитувана граматика (наприклад, Lark/EBNF), опис лексики, приклади коректних і некоректних програм.|
|CORE-02|1.5|Парсер та типізоване AST з позиціями у вихідному тексті (SourceSpan).|
|CORE-03|2.0|Інтерпретатор SIPL: стан змінних, присвоювання, композиція, if, while, begin/end, skip.|
|CORE-04|1.0|Подієва модель виконання та trace: Before/AfterStatement, зміна змінної, перевірка умови, завершення.|
|CORE-05|1.0|CLI: parse, check, run, trace; структурований JSON-режим для інтеграцій.|
|VIS-01|1.5|Візуалізація дерева синтаксичного виводу (parse tree) для SIPL-програми.|
|SEM-01|2.0|Автоматична побудова семантичного терму SIPL-програми в нотації курсу.|
|REL-01|0.5|CI: lint/type-check/tests на кожен Pull Request; збірка пакета/extension.|
|REL-02|0.5|GitHub Releases + SemVer + CHANGELOG для реалізованого модуля.|
|Сума балів|10.5 (макс. 10)|--|
